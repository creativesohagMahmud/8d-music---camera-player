# rehansCode

A powerful, full-featured mobile code editor for Android & Web.

### Features
- **Acode-inspired UI**: Dark modern theme with glowing cyan accents.
- **Node.js & Terminal Runtime**: Run `npm run dev`, `node`, and shell commands.
- **Git Support**: Commit and inspect repository changes.
- **350+ Plugins**: Prettier, Terminal, Python LSP, AI Copilot.
- **Touch Ergonomics**: Quick access keyboard symbols, line numbers, and search/replace.
